# master-builder

駒マスターデータは、公開リポジトリ・GitHub Pagesには一切含めません。
ユーザーが自分の端末（アプリの「設定」画面）へインポートするJSONファイルを、
手元で組み立てるためのツール群です。GitHub Pagesへの公開物にはPWA本体
（アプリのコード・空の雛形・スキーマ定義）のみを含め、駒マスターの実データや
攻略サイトの生アイコンは一切含めません。

## 現状（重要）

このプロジェクトの開発環境（サンドボックス）は `game8.jp` を含む外部サイトへの
アクセスが遮断されており、`robots.txt` ・利用規約・二次利用条件を確認できませんでした。
そのため、**本リポジトリには game8.jp 等からの自動取得（画像・テキストのスクレイピング）
は実装していません。**

`seedKnownPieces.mjs` は、ユーザーが過去に目視確認した駒名一覧（属性・ランク・
スキル等は未確認のため `"不明"`）から、アプリへインポートできる形式のJSONを
生成するサンプルスクリプトです。出力先は `tools/master-builder/output/`
（Git管理外、`.gitignore`で除外済み）で、**リポジトリへはコミットしません。**
生成したファイルは、アプリの「設定」→「マスタファイルを読み込む」から
ご自身の端末へインポートしてください。

## 実行可能なスクリプト

- `node tools/master-builder/seedKnownPieces.mjs`
  ネットワークアクセスなし。既知の駒名一覧から
  `tools/master-builder/output/master-known-pieces.json` を生成します
  （アプリへインポートする形式：`{schemaVersion, game, masterVersion, generatedAt, pieces[]}`）。
- `node tools/master-builder/generate-icons.mjs`
  ネットワークアクセスなし。`public/icons/source.svg`（自作のUI素材）からPWA用PNGアイコンを生成します。
  こちらは従来どおりリポジトリにコミットする対象です（駒の事実情報ではなくアプリ自身のUI素材のため）。

## 攻略サイトからの事実情報取得について

利用規約・`robots.txt`等の確認ができていないため、このツールに自動取得機能は
実装していません。実装する場合は、必ず対象サイトの利用規約・著作権表示・
二次利用条件を確認し、生画像は取得・保存せず、取得した事実情報はユーザー自身の
端末へインポートするファイルとしてのみ出力してください（公開リポジトリへは
含めない）。
